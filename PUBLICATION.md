### About the Paper

The paper presents a deep learning framework for multilingual sentiment
classification using uncased multilingual BERT (mBERT) representations. The
fine-tuned `bert-base-multilingual-uncased` model performs 5-class (1–5 star)
sentiment classification and is evaluated for cross-lingual generalization.
This repository ships the fine-tuned model weights, the evaluation harness, and
the figure-generation pipeline used to produce the results reported in the paper.
